# Запуск этого проекта

Этот проект создан специально для обычного Expo Go из App Store:

- SDK 54, потому что App Store-версия Expo Go в мае 2026 остается совместимой именно с SDK 54.
- Без `expo-router`, `expo-image`, `expo-symbols` и тяжелого starter-шаблона.
- Без глубоких iOS `xcframework`-папок, которые ломают удаление `node_modules` на Windows.

## Запуск

Открой PowerShell:

```powershell
cd C:\Users\BAZA\Desktop\YEST2\EmotionCheckInGo54
.\start-lan.cmd
```

Если снова будет `ECONNRESET`, попробуй:

```powershell
.\start-offline.cmd
```

В Expo Go можно сканировать QR-код или вручную ввести адрес `exp://...`, который появится в терминале.

## Если телефон не подключается

1. ПК и iPhone должны быть в одной Wi-Fi сети.
2. В Windows Firewall разреши `Node.js` доступ к частным сетям.
3. Отключи VPN/прокси/фильтрацию HTTPS на время запуска.
4. Не запускай старые проекты `EmotionCheckIn` и `EmotionCheckIn55` одновременно.
